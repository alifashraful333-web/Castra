CASTRA ICON UPDATE v3

Upload ALL files in this folder to the SAME root folder of the GitHub Pages repository, replacing index.html and sw.js if prompted. Keep the new versioned icon and manifest files in the repository root. Do not upload only the PNG files.

This keeps the current CASTRA HTML from the latest Members/Leaderboard update and uses versioned icon filenames so browsers must fetch the new assets. After GitHub Pages publishes, students should close CASTRA fully and open the website once while online; Chrome may update the installed PWA icon after it refreshes the manifest.

Important: Chrome/Windows can cache icons for already-installed apps independently. This package cannot remotely force every existing installed shortcut to change immediately. Some devices may only update after Chrome refreshes the installed app metadata, and a few may still require reinstalling. No student data is stored in these icon files.
