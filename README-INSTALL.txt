CASTRA PWA deployment

1. Upload ALL files in this folder to the same root folder of the GitHub Pages site (overwrite index.html with this version).
2. Keep manifest.webmanifest, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png, and favicon.svg beside index.html.
3. Commit/push and wait for GitHub Pages to publish. The site must be served over HTTPS.
4. Open the site in Chrome/Edge and use “Install CASTRA” or the browser menu > Install app. On iPhone/iPad, open in Safari > Share > Add to Home Screen.

Important: the app shell may open offline, but Supabase login, attendance, assessments and other live database features still require an internet connection.
